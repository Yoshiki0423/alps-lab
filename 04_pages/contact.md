# CONTACT(`/contact` および `/contact/thanks`)のワイヤーフレーム

## ページ全体の方針
- 雰囲気: ストイック・シンプル(フォームに集中させる)
- 主要色: ベース黒+赤(送信ボタン)
- アニメーション要素: 控えめ、フォームのフォーカス時のみハイライト

---

## メタ情報
- title: CONTACT | ALPS LAB
- description: ALPS LABへのお問い合わせ。入会相談・体験予約・法人取材・その他のご質問はこちらから。

---

## /contact のワイヤーフレーム

```
Header
↓
Hero "Contact"
↓
Form
├─ お問い合わせ種別(ラジオボタン)
│   ○ 入会相談
│   ○ 体験予約
│   ○ 法人・取材
│   ○ その他
├─ 名前(必須)
├─ メール(必須)
├─ 電話(任意)
├─ 希望店舗(セレクトボックス)
│   松本本店 / 長野店 / 軽井沢店 / 未定
├─ 本文(必須・テキストエリア)
└─ プライバシーポリシー同意(チェックボックス・必須)
↓
[送信] ボタン(大きく・赤またはゴールド)
↓
Footer
```

### バリデーション
- クライアントサイドバリデーション
- 必須項目のチェック
- メールアドレス形式チェック
- 電話番号形式チェック
- エラーメッセージは赤字でフィールド下に表示
- 送信成功 → /contact/thanks へ遷移

### 送信処理
- 課題なのでダミー処理でOK
- 実装方法: フォームsubmit時にpreventDefault → setTimeout後に thanks ページへ遷移

---

## /contact/thanks のワイヤーフレーム

```
Header(ミニマル)
↓
Hero "お問い合わせありがとうございました"
↓
メッセージ
"担当者より2営業日以内にご連絡させていただきます。"
↓
[TOPに戻る] ボタン
↓
Footer(ミニマル)
```

### 注意
- 直接URLでアクセスされても表示されるが、その場合のリダイレクト処理は不要(課題なので)
