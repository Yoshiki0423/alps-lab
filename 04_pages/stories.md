# STORIES(`/stories`)のワイヤーフレーム

## ページ全体の方針
- 雰囲気: 親しみゾーン(明度UP)
- 主要色: --color-bg-soft基調 + 黒テキスト
- アニメーション要素: カードのフェードイン、フィルタ切替時のスムーズトランジション

---

## メタ情報
- title: STORIES | ALPS LAB
- description: ALPS LABの会員インタビュー、コラム、お知らせ。健康とトレーニングのストーリーを発信します。

---

## ワイヤーフレーム

```
Header
↓
Hero "Stories"
↓
Filter: [All] [会員Voice] [コラム] [お知らせ]
↓
カード一覧(6〜8件)
┌──────┐ ┌──────┐ ┌──────┐
│ IMG  │ │ IMG  │ │ IMG  │
│Cat   │ │Cat   │ │Cat   │
│Title │ │Title │ │Title │
│抜粋  │ │抜粋  │ │抜粋  │
│ Date │ │ Date │ │ Date │
└──────┘ └──────┘ └──────┘
※詳細記事ページなし、リンクは「Coming Soon」
※カテゴリフィルタはJSで簡易実装
↓
CTA + Footer
```

---

## 機能要件
- カテゴリフィルタリング(JS実装)
  - クリックで該当カテゴリのみ表示、他はフェードアウト
- 詳細記事ページは作らない
- 各カードのクリック先は「Coming Soon」の小さなオーバーレイまたはトップに戻る
