# エージェント間の中間成果物伝達フォーマット

> Designer→Coderへの引き継ぎ品質を担保するため、中間成果物の形式を以下に固定する。

---

## Designer Agentの成果物

### 成果物1: 参考サイト分析レポート

**ファイル**: `work/design/01_reference_analysis.md`

各参考サイト(5つ)について、以下のフォーマットで分析する。

```markdown
## {サイト名}

### 取り入れる要素(3~5項目)
- 要素1: {何を取り入れるか・どこに使うか}
- 要素2: ...

### 取り入れない要素(理由付き)
- 要素X: {ALPS LABの世界観と合わないため等}

### ALPS LABへの応用案
- 具体的にどのページのどのセクションで使うか
```

---

### 成果物2: 確定版デザイントークン

**ファイル**: `work/design/02_design_tokens.css`

`03_design/design_tokens.md` を起点にCSS変数を確定。
そのままCoderが `assets/css/tokens.css` として使えるようにする。

### 成果物3: 詳細ワイヤーフレーム(全11ページ分)

**ファイル**: `work/design/03_wireframes/{ページ名}.md`

`04_pages/{ページ名}.md` を起点に、より詳細にビジュアル設計を加える。
各ファイルに以下を含める。

```markdown
# {ページ名} 詳細ワイヤーフレーム

## ページ全体の方針
- 雰囲気: ストイック / 親しみ
- 主要色: ベース黒 / アクセント赤・ゴールド
- アニメーション要素: ◯◯のフェードイン / ◯◯のパララックス
- 参考サイトとの関連: {どの参考サイトのどの要素を取り入れたか}

## セクション構成

### Section 1: {セクション名}
- 高さ: ◯vh または ◯px
- 背景: {色・画像・動画}
- テキスト位置・配置
- フォント: {フォント名・サイズ}
- 動き: {アニメーションの内容}
- レスポンシブ挙動: {1024px以下、768px以下、480px以下それぞれ}

### Section 2: ...
```

---

### 成果物4: HTMLモックアップ(主要3ページのみ)

**ファイル**: `work/design/04_mockups/{ページ名}.html`

以下の3ページのみ、実際のHTML/CSSモックアップを作成する。
Coderが土台として使うため、本番に近い完成度で作る。

- `04_mockups/index.html`(TOP)
- `04_mockups/services_gym.html`(SERVICES/GYM)
- `04_mockups/about.html`(ABOUT)

要件:
- デザイントークン(成果物2)を読み込む
- アニメーションは仮実装でOK(コメントで明記)
- 画像はUnsplash / Pexels等のフリー素材URLかプレースホルダー
- レスポンシブは1280px時点での見栄えを最優先
