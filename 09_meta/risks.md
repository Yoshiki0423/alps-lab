# リスクと対応方針

| リスク | 対応方針 |
|---|---|
| 動画背景がモバイルで重くなる | モバイルではポスター画像に切り替え、または短い軽量動画を別途用意 |
| GSAPの読み込み失敗 | CDN障害時のフォールバック(動きなしでも閲覧可能な設計) |
| 画像素材の著作権 | Unsplash / Pexels等のフリー素材のみ使用、出典をREADMEに明記 |
| Vercelデプロイ失敗 | 静的サイトなのでフォルダごとアップロードする手動デプロイにも対応可能 |
| エージェント間の指示伝達ミス | 中間成果物を必ずファイル化(Markdown)し、PM Agentが集約。`08_workflow/handoff_format.md` を厳守 |
| トークン制限超過 | ファイル分割により1タスクあたりの読み込み量を最適化 |
| 過剰演出によるパフォーマンス低下 | Lighthouse Performance 80+ を最低基準とし、達成困難な場合は演出を削減 |
| デザインの統一感が崩れる | Reviewer Agentによるデザイン一貫性チェックを必須化 |
