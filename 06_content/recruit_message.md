## 募集職種

### 1. パーソナルトレーナー

- 雇用形態: 正社員 / 業務委託
- 勤務地: 松本本店 / 長野店 / 軽井沢店
- 求める人物像: NSCA-CPT等の資格保有者歓迎、未経験でも研修制度あり

### 2. 管理栄養士

- 雇用形態: 正社員 / パート
- 勤務地: 松本本店(本社)/ オンライン
- 求める人物像: 管理栄養士資格保有者、コーチング経験者歓迎

### 3. 商品開発(FOODS / SUPPLEMENTS)

- 雇用形態: 正社員
- 勤務地: 松本本店(本社)
- 求める人物像: 食品開発経験者、または栄養学のバックグラウンド

### 4. 店舗運営マネージャー

- 雇用形態: 正社員
- 勤務地: 各店舗
- 求める人物像: 接客業・サービス業のマネジメント経験者
