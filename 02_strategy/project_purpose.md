# ALPS LAB プロジェクトの目的・優先順位・スコープ

## プロジェクトの目的(優先順位順)

1. **ブランディング** — 企業の理念や世界観を伝え、信頼感を醸成する(最優先)
2. **事業紹介** — 複数事業の全体像を分かりやすく伝える
3. **新規会員の獲得** — ジム入会の問い合わせ・体験予約を増やす
4. **EC・商品認知** — プロテインや冷凍食品の販売促進
5. **採用** — トレーナー・栄養士などの応募を集める

→ つまり、**広告色の強いLPではなく、世界観で魅せるブランドサイト**を作る。

---

## スコープ

### 含むもの

- コーポレートサイト本体(全12ページ規模)
- レスポンシブ対応(4ブレークポイント)
- Vercelデプロイ
- お問い合わせフォーム(クライアントサイドのみ、ダミー送信)

### 含まないもの

- ECサイト本体
- 会員マイページ・ログイン機能
- 予約管理システム(バックエンド)
- CMS構築・記事詳細ページ
- 多言語対応

### 過剰実装を防ぐための制約

- ヒーロー動画は3~5秒のループに収める(ファイルサイズ最大3MB)
- 各ページの画像点数は最大8枚まで
- アニメーションライブラリはGSAPのみ(他は使わない)
- フォント数はGoogle Fonts 3種類まで(Bebas Neue / Noto Sans JP / Inter)
