# ALPS LAB レスポンシブルール

## ブレークポイント定義

```css
/* Desktop Large */ @media (min-width: 1280px) { ... }
/* Desktop / Tablet Landscape */ @media (max-width: 1279px) and (min-width: 1024px) { ... }
/* Tablet Portrait */ @media (max-width: 1023px) and (min-width: 768px) { ... }
/* Mobile */ @media (max-width: 767px) { ... }
```

| 名称 | 幅 |
|---|---|
| Desktop Large | 1280px以上 |
| Desktop | 1024~1279px |
| Tablet | 768~1023px |
| Mobile | ~767px |

## モバイル特有の最適化

### 動画背景の切替
- 動画背景 → 静止画ポスターに切替(パフォーマンス対策)
- `<video>` 要素は `display: none` または非読み込み
- 代わりに `<img>` でポスター画像を表示

### ヘッダー
- ヘッダーCTAボタン → アイコンのみまたは「予約」テキストに短縮
- ハンバーガーメニュー展開時はフルスクリーンオーバーレイ

### CTA
- 最下部にCTA固定バー(Fixed Footer)を表示する案も検討
- 主要CTAはサムタッチ可能なサイズ(最小44×44px)を確保

### フォントサイズ
- 見出しは1段階小さく(例: 64px → 40px)
- 本文は16px下回らない(可読性確保)

### 画像
- `srcset` で複数サイズ用意するのが理想だが、最低限モバイル用WebPは別途用意
- 縦長画像は16:9から4:3や1:1に切り替えて対応

## レスポンシブ実装の原則

### モバイルファースト
- 基本スタイルはモバイル(~767px)向けに書く
- `@media (min-width: 768px)` で大画面向けに上書き
- これにより読み込みコストを最小化

### 文字の改行
- 日本語の「自動改行」は `word-break: keep-all` か `<br class="sp-only">` で明示
- 重要なキャッチコピーは改行位置を意図的にコントロール

### タッチ操作対応
- ホバーエフェクトに依存しない設計(タッチデバイスにはホバーがない)
- ボタン・リンクは最低44×44pxのタッチ領域を確保
