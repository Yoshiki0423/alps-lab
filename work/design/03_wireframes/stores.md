### 長野店:画像右 / 情報左(左右反転)、軽井沢店:画像左 / 情報右(松本本店と同型)

### 仕様

| 項目 | 値 |
|---|---|
| 高さ | 80vh(min 600px)|
| 背景 | `var(--color-bg-primary)` / 偶数番店舗は `var(--color-bg-secondary)` |
| 横分割 | 50:50 grid |
| 画像エリア | フィルター brightness 0.85、ホバー時 1.0 + scale 1.02 |
| 章番号 + 都市名(英語ラベル): font-en, var(--fs-2xs), letter-spacing: var(--ls-widest), gold |
| 英語タイトル: font-display, var(--fs-3xl), white |
| 日本語: font-jp bold, var(--fs-xl) |
| 区切り罫線: 1px gold opacity 0.3 |
| 情報リスト: font-jp, var(--fs-base), color-text-secondary |
| ボタン2種: 「Google Map で開く」(gold枠線)+「体験予約」(red塗り) |

### アニメーション

- スクロール時、画像が左/右からスライドイン+フェードイン
- 情報側は 200ms 遅れてフェードイン

### レスポンシブ

| BP | 配置 |
|---|---|
| 1280+ | 50:50 横並び、左右交互 |
| 1024+ | 同上 |
| 768+ | 縦並び(画像上、情報下) |
| 〜767 | 縦並び |
