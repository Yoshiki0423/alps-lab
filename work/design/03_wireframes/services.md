# SERVICES `/services` 詳細ワイヤーフレーム

## ページ全体の方針

- 雰囲気: ストイック・知的(料金は前面に出さず、4事業を「研究領域」として見せる)
- 主要色: ベース黒 + ゴールドアクセント

- 参考サイトとの関連:

  - **Flexova**: 横長カード左右交互配置

```
│              └──────────┬───────┘                           │
│                         ↓                                    │
│              ┌──────────────────┐                           │
│              │ 02  栄養指導で    │                           │
│              │     食事改善      │                           │
│              └──────────┬───────┘                           │

│              ┌──────────────────┐                           │
│              │ 03  冷凍食品で実行 │                           │

│              ┌──────────────────┐                           │
│              │  → 継続的な健康   │ ← gold背景・強調         │
│              └──────────────────┘                           │
└────────────────────────────────────────────────────────────┘
```

### 仕様

| 項目 | 値 |
|---|---|
| 背景 | `var(--color-bg-secondary)` |
| ノード | 横長 480x100px、背景 `var(--color-bg-tertiary)`、左に gold 縦罫線 |
| 矢印 | 縦罫線+下向き三角、gold |
| 最終ノード | gold 背景 + 黒テキスト(強調)|
| 番号: font-en, var(--fs-md), letter-spacing: var(--ls-wider), gold |
| 内容: font-jp bold, var(--fs-md), white |

### アニメーション(目玉)

- スクロール 30% 進入で各ノードが上から下へ順次フェードイン(stagger 300ms)
- 矢印が縦に伸びる(scaleY 0 → 1)
- 最終ノード「継続的な健康」が登場時に gold glow パルス1回(`box-shadow: var(--shadow-glow-gold)`)

### レスポンシブ

| BP | 幅 |
|---|---|
| 1280+ | ノード幅 480px |
| 1024+ | ノード幅 400px |
| 768+ | ノード幅 80%(画面相対)|
| 〜767 | ノード幅 90%、矢印短縮 |
