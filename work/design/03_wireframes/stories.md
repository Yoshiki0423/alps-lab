```
│ │ ─────    │ │ ─────    │ │ ─────    │                    │
│ │ 抜粋…    │ │ 抜粋…    │ │ 抜粋…    │                    │

└────────────────────────────────────────────────────────────┘
```

### 仕様

| 項目 | 値 |
|---|---|
| 背景 | `var(--color-bg-soft)` |
| 3カラム(Desktop)→ 2カラム(Tablet)→ 1カラム(Mobile) |
| カード数 | 6〜9件(news 3 + voices 3 + columns 3 程度) |
| 画像比率: 4:3 |
| カード背景: 白 #FFFFFF or transparent(soft 背景に同化させる) |
| カテゴリラベル: font-en, var(--fs-2xs), letter-spacing: var(--ls-widest), gold |
| タイトル: font-jp bold, var(--fs-md), color-text-soft |
| 抜粋: font-jp, var(--fs-sm), color-text-soft, opacity 0.7, 2行省略 |
| 日付: font-en, var(--fs-xs), color: #888 |

### クリック時の挙動

- 各カードクリックで小さなオーバーレイ「Coming Soon」を表示(中央配置・閉じるボタン付き)
- または該当カードに `aria-disabled="true"` を付け、クリックで小さなトーストを出す

### アニメーション

- スクロールで stagger フェードイン
- フィルタ切替時:
  1. 全カード opacity 1 → 0(200ms)
  2. JSで該当カテゴリ以外を `display: none`
  3. 該当カードが opacity 0 → 1 + translateY(8px → 0)(300ms)
