### 仕様

### フォーム要素のスタイル

| 要素 | スタイル |
|---|---|
| ラベル | font-jp, var(--fs-sm), color-text-secondary, letter-spacing: 0.04em, 必須項目は赤 `*` を末尾に |
| ラジオボタン | 横並び4項目、カスタムスタイル(円 + gold チェック)|
| input / textarea | 背景 transparent、border 1px var(--color-border-soft)、padding 0.75rem、color-text-primary |
| input フォーカス時 | border 1px gold、box-shadow `0 0 0 3px rgba(200,169,97,0.15)` |
| select | 上に同じ、矢印は gold |
| textarea | min-height 160px |
| チェックボックス | カスタムスタイル(四角 + gold チェック)|
| 送信ボタン | 赤背景、padding 1.25rem 4rem、font-jp medium, var(--fs-md)、ホバーで red-hover + glow |

### バリデーション

- HTML5 required + JSバリデーション併用
- 必須未入力: フィールド下に赤字エラーメッセージ + フィールドの border を red に
- メール: `type="email"` + 正規表現でフォーマットチェック
- 電話: `pattern="[0-9-]+"` + 半角数字+ハイフンのみ
- 同意未チェック: 送信不可、エラーメッセージ表示

### 送信処理(課題なのでダミー実装)

```js
form.addEventListener('submit', (e) => {
  e.preventDefault();
  // 簡易バリデーション
  if (!validate()) return;
  // ローディング演出(ボタンを「送信中...」に)
  setTimeout(() => {
    window.location.href = '/contact/thanks/';
  }, 800);
});
```

### アニメーション

- 各フォーム要素がスクロール時に下からフェードイン(stagger 80ms)
- フォーカス時にラベルがgold色に変化(200ms)

### アクセシビリティ

- すべての input に `<label for="...">` 紐付け
- エラーメッセージは `aria-live="polite"` + `aria-invalid="true"`
- 送信ボタンはキーボード(Enter)で送信可能
- フォーカスリング: `outline: 2px solid gold`
