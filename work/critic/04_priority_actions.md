## 🔴 最優先(必須改善:4件)

### 🔴 P1. 体験予約専用ページ `/trial/` の新設
- **影響軸**: W5(コンバージョン誘導)6→8 / W3(ナビ)6→7
- **解決する問題**: 田中・佐藤・鈴木の3ペルソナ全員が CONTACT 流用フォームで離脱率を上げている。BEYOND など競合は専用ページが標準。
- **実装内容**:
  - 新規ページ `/trial/index.html` を作成
  - ヒーロー: 「体験予約 — 当日の流れ」(60分・カウンセリング15分+体験45分の3ステップ図解)
  - フォーム5項目のみ: 氏名・連絡先(メール+電話任意)・希望店舗(3拠点)・希望日時2候補(日付ピッカー)・希望プラン(LIGHT/STANDARD/PREMIUM/迷っている)
  - フォーム下に「初心者です」「女性専用エリア利用希望」「持病があります」のチェックボックス3つ
  - サンクスページ `/trial/thanks/`: 「24時間以内に担当者からご連絡」「体験当日の持ち物」「キャンセルポリシー」
  - 既存 `/contact/?type=trial` は `/trial/` への 301 リダイレクトに変更
  - ヘッダー CTA・各ページの全 CTA を `/trial/` に張替
- **想定作業時間**: 4〜6時間(HTML/CSS/JS + サンクスページ + リダイレクト)
- **期待効果**: 3ペルソナ平均離脱率 52% → 35〜40% 想定(BEYOND型の専用予約フォーム導入後の典型値)

### 🔴 P2. 顧問医師セクション(ABOUT)+ 管理栄養士の顔出し充実(NUTRITION)
- **影響軸**: W7(トラスト)5→7 / W1(ブランド表現)9→10
- **解決する問題**: 「研究」を謳いながら、研究の人(医師・栄養士)が見えない。佐藤(45/経営者)が「誰が指導するか分からない」と離脱する直接要因。
- **実装内容**:
  - **ABOUT にセクション「ADVISORS / 顧問チーム」を新設**:
    - 3名分(顧問医師2名+顧問栄養学者1名 等の構成)
    - 各カード: 顔写真(モノクロ・ゴールド細罫線、fitlab 流) / 実名 / 所属(例: 信州大学医学部 准教授) / 専門領域 / 経歴200字
    - 配置: ABOUT の TEAM セクションの直前、独立セクション
    - ダミーで可だが「架空」表記をやめ、設定として人物像を確定する
  - **NUTRITION ページ「DIETITIAN / 管理栄養士紹介」セクションの実装**:
    - 既存の名前のみ(小林由香・高橋沙織)を、顔写真+保有資格+専門領域+セッション風景写真+メッセージ100字 に拡張
    - 各カード: モノクロ顔写真(120×120px) / 実名 / 「管理栄養士・国家資格」「公認スポーツ栄養士」等の資格 / 専門(スポーツ栄養 / 経営者向け健康食 等) / 1セッションの風景写真
- **想定作業時間**: 6〜8時間(コンテンツ作成3〜4h + 実装3〜4h)
- **期待効果**: 佐藤の離脱率 65% → 30〜40%(顧問医師は経営者層の信頼形成の核)

### 🔴 P3. TOP ヒーロー直下に「1行サマリー」+「セカンダリCTA」を追加
- **影響軸**: W4(ファーストビュー)7→9
- **解決する問題**: `final_review.md` で既に指摘されているが未対応。「これは何のサイトか」が3秒で伝わらず、田中・佐藤の初動で「何屋?」の混乱が発生。
- **実装内容**:
  - 「RESEARCH THE TRUTH OF HEALTH」+ 「北アルプスの麓から…」コピーの直下に、以下の1行サマリーを挿入:
    ```
    24時間ジム × パーソナル / 栄養指導 / 冷凍宅配 / サプリメント
    — 長野発の4事業で、30年続く健康習慣を設計する。
    ```
    - フォント: Noto Sans JP 16〜18px、line-height 1.7、ゴールド 60% 透過の細罫線で囲む(上下各 1px)
  - **セカンダリCTA「料金プランを見る」を追加**:
    - プライマリ「体験予約はこちら →」(赤・ソリッド)と並列、ゴーストボタン(ゴールド枠線・透明背景)
    - リンク先: `/services/gym/#pricing`(GYM ページの料金セクションへアンカー)
  - **ヒーロー右下に小さな数値プルーフ**(任意・余力ありなら):
    - 「3 STORES / 4 FIELDS / 12+ TRAINERS / 30 YEARS' RESEARCH GOAL」
    - Inter 12px ゴールド、画面右下隅
- **想定作業時間**: 2〜3時間(コピー文言確定 + HTML/CSS 実装)
- **期待効果**: 初見3秒で「何屋か」が伝わる比率 30% → 80%(推定)

### 🔴 P4. FAQ の大幅拡張(GYM 5→20件、NUTRITION/FOODS/SUPP 各 0→10件)
- **影響軸**: W10(コンテンツ)6→8 / W5(CV誘導)6→7
- **解決する問題**: 田中(38/会社員)が GYM FAQ 5件で「退会・休会・シャワー・駐車場が分からない」と離脱の50%を占める要因。NUTRITION/FOODS/SUPP は FAQ ゼロで購入直前の不安を解消できない。
- **実装内容**:
  - **GYM FAQ 5→20件**(以下のカテゴリで各2〜4件):
    1. 営業・利用時間(2件)
    2. 入会手続き(2件)
    3. プラン変更・休会・退会(4件) ← 田中の最重要
    4. 設備・施設(3件:シャワー・駐車場・タオル・ロッカー)
    5. パーソナルセッション(3件:振替・キャンセル料・トレーナー指名)
    6. 安全・初心者(3件:初心者OKか・夜間スタッフ・女性専用エリア) ← 鈴木の最重要
    7. その他(3件:子供連れ・体験当日・退会後の再入会)
  - **NUTRITION FAQ 0→10件**: 初回の流れ・オンライン/対面の違い・キャンセル料・食事記録の方法・継続の頻度・特定疾患対応 など
  - **FOODS FAQ 0→10件**: 配送日数・冷凍保存期間・温め方・アレルギー・定期解約・送料 など
  - **SUPP FAQ 0→10件**: 飲み方・併用・原料・第三者検査・保管・定期購入解約 など
  - 共通実装: `<details>` ベースのアコーディオン or 既存 GYM FAQ コンポーネントの再利用
- **想定作業時間**: 8〜10時間(コンテンツ執筆6〜7h + 実装2〜3h)
- **期待効果**: 田中・鈴木の懸念事項を直接解消、各事業ページの滞在時間 +30%、離脱率 -10〜15%

## このリストの使い方(Phase 3 への引き継ぎ)

1. **まず Sprint 1 の 🔴 4件を実施**(商業リリース可能ラインの突破)
2. Sprint 1 完了後に Critic Agent を再実行(本ファイルと同じ評価軸で再採点)
3. 80点を超えたら Sprint 2 へ進む(任意・時間とROIで判断)
4. Sprint 2 後に再評価し、業界トップを狙うなら Sprint 3 へ

各項目の「実装内容」は Coder Agent がそのまま着手できる粒度で記述している。
不明点があれば該当項目の「期待効果」と「影響軸」を起点に、`02_persona_simulation.md` と
`03_critique_report.md` を再参照すること。
