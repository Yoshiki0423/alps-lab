## W1. コンセプト・ブランド表現 — **9 / 10** ★★★

### 良い点(称賛側)
- **「北アルプスの麓から、本物の健康を研究する」のコピー**が、12ページ全体の指針として機能。これは Phive Clubs と同等の強度。
- **Split Composition「NATURE × BODY」** の構図は5つのベンチマークサイトいずれにもない**ALPS LAB 独自の表現**。「自然」と「身体」を1画面で対置する勇気と完成度は、Awwwards SOTD 級。
- **章番号(MISSION 01 / FOUR FIELDS / RESEARCH N°05 など)** と **地理座標(LAT 36.2°N / LON 137.9°E)** で「研究レポート風」の独自世界観を全ページに展開できている。fitlab を一段超える表現。
- **カラー比率(黒80-90% / ゴールド3-5% / 赤1-3%)** が12ページで揺るがない。Phive Clubs 同等の徹底度。

### 業界水準との比較
- Phive Clubs / fitlab と**同レベル**の世界観構築力。
- ただし fitlab は「研究」を**実際のデータビジュアル(計測値・グラフ)** で示す部分があり、ALPS LAB は比喩(章番号・座標)に留まっている。

### 改善案(具体)
1. **「研究」の証拠ビジュアル**を ABOUT または TOP に追加:
   - ダミーで良いので「会員平均の体脂肪率推移グラフ」「年間カウンセリング件数」「累計研究レポート公開数」のような数値ダッシュボード風セクション
   - サイズ感: TOP の WHY ALPS LAB セクション直後に「RESEARCH SUMMARY 2025」として 1セクション
2. **顧問医師・栄養士の白衣写真**を ABOUT に配置(W7の改善と統合)
3. **「研究員(=トレーナー)プロフィール」**で資格を強調

→ これだけで W1 を **10/10** に押し上げ可能。

## W2. 情報設計・サイトマップ — **7 / 10** ★★★

### 良い点
- 12ページ構成は、4事業 × 詳細 + 共通ページという**ロジカルな分割**。
- TOP → SERVICES → 各事業詳細 → CONTACT のフロー自体は標準的。
- フッターの4列構成(Services / Stores / Company / Social)は Snow Peak 同等の品格。

### 業界水準との比較(劣る点)
- Phive Clubs は5〜6ページ程度で完結している。**12ページは多すぎ**。
- 特に `/services/`(一覧)が **TOPの「FOUR FIELDS」セクションと内容重複**しており、初見ユーザーは「どっちを見ればいい?」と迷う。
- COMPANY と ABOUT の役割分担が薄い(ABOUTがブランドメッセージ、COMPANYが法人情報、と分かれているが、ABOUTにも沿革があり重複感がある)。
- RECRUIT の情報量が薄く、**ABOUT 内のセクションに統合**したほうが密度が上がる選択肢があった。

### 改善案(具体)
1. **`/services/` の役割を再定義**:
   - 一覧ページとして残すなら **TOPの FOUR FIELDS と差別化** する(料金比較表・各事業の関係性図・契約パターン提示など)
   - またはこのページ自体を廃止し、ヘッダーから直接各事業ページへ遷移(W3 の改善と連動)
2. **COMPANY を ABOUT 末尾の小セクションへ統合**(代表者・住所・資本金のテーブル形式で1セクション)、`/company/` を廃止 → 12 → 11ページに
3. **RECRUIT を ABOUT 末尾の「採用」セクションへ統合**するか、現状維持なら**社員インタビュー記事を3本追加**して密度を上げる

## W3. ナビゲーション設計 — **6 / 10** ★★★

### 良い点
- 主要5項目(About / Services / Stores / Stories / Recruit)+ CTA(体験予約)の構成は標準的で理解しやすい。
- ハンバーガーメニュー(モバイル)と PC 横並びの切り替え対応。
- ヘッダーの透過 → ソリッド黒の切替挙動(Phive 流)。

### 業界水準との比較(劣る点)
- **メガメニュー / ドロップダウンが無い**。Services クリック → 一覧ページ経由で各事業へ、は **1クリック余分**。Phive Clubs / BEYOND は当然のようにメガメニューを持っている。
- **パンくずリスト未実装**。`TOP > SERVICES > GYM` のような階層表示がない。12ページ規模では必須レベル。
- **COMPANY / CONTACT がヘッダーから消えている**(フッター送り)。CONTACT は CTA とは別経路として、文章相談用の窓口を残すのがコーポレートサイト標準。
- **検索機能なし**。Snow Peak は持っている。STORIES が拡張すると必須に。

### 改善案(具体)
1. **ヘッダー Services のホバー時メガメニュー**:
   - 4事業(GYM / NUTRITION / FOODS / SUPPLEMENTS)を画像付きカード4枚で表示
   - 実装: GSAP の opacity + translateY で 200ms フェード
2. **全下層ページにパンくずリストを追加**:
   - 例: `TOP / SERVICES / GYM` のフォーマット、Inter 12px ゴールド。記号は ` / `
   - ヒーロー直下、コンテンツ開始の手前に固定
3. **ヘッダー右側 CTA の隣に「お問い合わせ」テキストリンクを追加**(細字、CTAと並列)。これで体験予約と一般相談を分離視覚化

## W4. ファーストビューの完成度 — **7 / 10** ★★★

### 良い点
- 「Split Composition / NATURE × BODY」は**強烈に印象に残るデザイン**で、3秒以内に「ただのジムサイトじゃない」と認識させる力がある。
- `RESEARCH THE TRUTH OF HEALTH.` の英文・「北アルプスの麓から、本物の健康を研究する。」の和文の対比が機能している。
- カラーリング・タイポグラフィの完成度は業界トップ級。

### 業界水準との比較(劣る点)
- **「これは何のサイトか」が3秒で伝わらない**(`final_review.md` で既に指摘されているが未対応)。
  - `RESEARCH THE TRUTH OF HEALTH` だけでは「ジム」「栄養」「冷凍食品」「サプリ」という事業内容が一切伝わらない。
- **セカンダリ CTA が無い**。BEYOND / Phive はプライマリ(JOIN)+セカンダリ(料金 / 店舗)を必ず併置している。今は「予約 OR スクロール」の二択しか無く、迷ったユーザーが離脱するリスク。
- 章番号(MISSION 01 / FOUR FIELDS など)はあるが、**ヒーロー直下の1行サマリー** がない。

### 改善案(具体)
1. **ヒーロー下に1行サマリーを追加**:
   - コピー案: 「**24時間ジム × パーソナル / 栄養指導 / 冷凍宅配 / サプリメント — 長野発の4事業で、30年続く健康習慣を設計する。**」
   - フォント: Noto Sans JP 16〜18px、line-height 1.7、ゴールド 60%透過の細罫線で囲む
   - 配置: 「RESEARCH THE TRUTH OF HEALTH」のさらに下、CTA ボタンの上
2. **セカンダリ CTA「料金プランを見る」を追加**:
   - プライマリ「体験予約はこちら」と並列、ゴーストボタン(枠線のみ・透明背景)
3. **ヒーロー右下に小さな数値プルーフ**:
   - 「3 STORES / 4 FIELDS / 12+ TRAINERS / 30 YEARS' RESEARCH GOAL」のような英数表記(fitlab 流)

→ これだけで W4 を **9/10** に押し上げ可能。

## W6. ビジュアル階層・タイポグラフィ — **8 / 10** ★★

### 良い点
- 3フォント体制(Bebas Neue / Noto Sans JP / Inter)を**役割別に厳密に運用**。
- 章番号と本文の視覚階層が機能(過去のフォントサイズ修正で対応済み)。
- 余白の取り方が大胆(Snow Peak 同等)、安っぽくならない。

### 業界水準との比較(微差)
- **行間(line-height)の統一**: 日本語本文の line-height が場所によって異なる可能性。1.7 〜 1.8 のどちらかに揃えるのが望ましい。
- **数字の揃え方**: 料金「¥8,800」「¥22,800」のような数字が縦で揃っていない。`font-feature-settings: "tnum"` または `font-variant-numeric: tabular-nums` で固定幅にすべき。
- **強調表現の弱さ**: 重要な単語(「**本物**」「**研究**」「**30年**」)に色変えや下線などの装飾が無い。読み流しを防ぐマーカーが少ない。

### 改善案
1. CSS変数 `--line-height-body: 1.75` を全ページの本文に統一適用
2. 料金関連クラスに `font-variant-numeric: tabular-nums;` を追加
3. ブランドキーワード(`<em class="brand-emph">`)用のスタイルを定義(ゴールドの細い下線)

## W8. アクセシビリティ — **8 / 10** ★★

### 良い点
- Reviewer Agent 確認済の標準的な対応(alt 属性、セマンティック HTML、コントラスト比 WCAG AA)。
- `prefers-reduced-motion: reduce` 配慮。
- スキップリンク実装済。

### 業界水準との比較(微差)
- **フォーカス可視化のブランド対応**: 黒×ゴールド基調なのだから、フォーカス枠は**ゴールドの2px破線**で明示するとブランド感が増す。
- **CONTACT フォームのエラーハンドリング**: `aria-invalid` と `aria-describedby` の連携が記述されていない可能性。スクリーンリーダーユーザーにエラーが伝わりにくい。
- **キーボードナビのテスト**: ハンバーガー、FAQアコーディオン、フォーム送信を Tab キーだけで完了できるか手動確認が望ましい。

### 改善案
1. `:focus-visible` で `outline: 2px dashed var(--color-accent-gold); outline-offset: 4px;` を全インタラクティブ要素に
2. CONTACT フォームに `aria-invalid` / `aria-describedby` / エラーメッセージ ID 連携
3. 手動キーボードテスト実施 → `work/critic/keyboard_test.md` に結果記録

## W9. レスポンシブ・デバイス対応 — **7 / 10** ★

### 良い点
- 4ブレークポイント(1280 / 1024 / 768 / 480)で設計。
- ハンバーガーメニュー・カラム数切替・画像サイズ最適化など標準対応。

### 業界水準との比較(劣る点)
- **モバイルのファーストビュー**: Split Composition は PC 向けの構図。モバイルでは縦に2分割すると窮屈になりやすい。**モバイル専用の構図**(山岳画像 → キャッチ → 人物画像 の縦並び 3分割)を検討すべき。
- **タッチターゲット**: ボタンや文字リンクが**44px×44px 以上**を確保しているか要確認(Apple HIG 最小推奨)。
- **動画ロード**: モバイルでは静止画フォールバックだが、`<video preload="none">` の指定 + ポスター画像表示を確実にすべき。
- **iOS Safari 100vh 問題**: `min-height: 100svh` を使うべき(small viewport units)。

### 改善案
1. モバイル(<768px)時の Hero を「縦3ブロック」構図に切替(山 / コピー / トレーニング画像)
2. 全 button / a タグに `min-width: 44px; min-height: 44px;` を強制適用するユーティリティクラス
3. Hero `<video>` に `preload="none"` + `poster` 属性を必須化
4. 全 100vh の指定を `100svh`(フォールバック `100vh`)に変更

## W10. コンテンツの質・量バランス — **6 / 10** ★

### 良い点
