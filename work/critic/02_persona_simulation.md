# 02. ペルソナ・シミュレーション(3名のサイト巡回 → 申し込み判断)

> 作成: 2026-05-06 / Critic Agent
> 対象: https://alps-lab.vercel.app/
> 方法: `01_brand/target_persona.md` の3ペルソナそれぞれの立場でサイトを巡回し、
>       各ステップで「申し込みたい / どちらでもない / 離脱する」を判定。
>       本サイトの WebFetch 結果(TOP/ABOUT/SERVICES/GYM/NUTRITION/FOODS/SUPPLEMENTS/STORES/STORIES/RECRUIT/COMPANY/CONTACT)
>       を一次情報として使用。

---

## 0. 判定の凡例

- ✅ **申し込みたい**:そのまま予約フォームへ進む心理状態
- 🟡 **どちらでもない**:留まるが、迷っているので離脱の可能性も残る
- ❌ **離脱する**:タブを閉じる、または競合サイトへ流出

## A. 田中健一(38歳/男性/松本/IT中堅) — STANDARD想定

### A.1 検索流入とTOP訪問
- スマホで「松本 ジム パーソナル」検索 → 公式リンクから流入
- ファーストビュー:
  - 「RESEARCH THE TRUTH OF HEALTH」+「北アルプスの麓から、本物の健康を研究する」
  - 山岳画像 + アスリート画像の Split Composition
- **田中の心の声**: 「かっこいい。でも、これって何のサイト?ジム?サプリ?食事?」
  - **判定: 🟡 どちらでもない**(ブランドは伝わるが、事業内容が即伝わらない)

### A.2 スクロールして MISSION → FOUR FIELDS
- MISSION の「30年続く健康習慣」コピーで「効率より本質寄りのジムだな」と認識
- FOUR FIELDS で 4事業(GYM/NUTRITION/FOODS/SUPPLEMENTS)の存在を初めて把握
- **田中の心の声**: 「事業多いな。とりあえずGYMの料金が見たい」
  - **判定: 🟡 どちらでもない**(やっと事業内容が分かる、ただ4事業が広すぎてジムだけ知りたい人には冗長)

### A.3 ヘッダーから SERVICES → 一覧 → GYM へ
- SERVICES 一覧をクリック → GYM の概要が長く、4事業の中で GYM 詳細リンクから個別ページへ
- 1クリック余分(田中は効率重視のため、ここで微妙に苛立つ)
- **改善示唆**: ヘッダー「Services」のホバーで GYM/NUTRITION/FOODS/SUPPLEMENTS のドロップダウンが必要

### A.4 GYMページ
- ヒーロー → 施設写真6種 → **料金プラン3種(STANDARD に OUR PICK ラベル)** → トレーナー3名 → フロー → FAQ 5件
- **田中の心の声**:
  - 「STANDARD 14,800円か。月2回パーソナル+24時間ジム、BEYONDの5万円より明らかに安い」(納得)
  - 「トレーナー3名、経歴がやや薄いな。BEYONDのページではコンテスト実績が並んでた」
  - 「FAQ 5件は少ない。退会条件、休会、振替、シャワー時間、駐車場…知りたいことが書いてない」
- **判定: 🟡 どちらでもない**(料金は刺さるが、退会条件等の不安が残る)

### A.5 STORIES → VOICE
- VOICE 3件中に「田中健一さん 38歳 STANDARD会員」がある
- **田中の心の声**: 「自分と同じ属性の人が結果出してるのは安心」(◎)
- ただし合計3件しかなく、「サクラっぽい?」という疑念も10%発生
- **判定: 🟡 どちらでもない**(同属性VOICEは加点だが、母数が少なくて信用度が物足りない)

### A.6 体験予約クリック
- ヘッダー or GYMページ末尾のCTAをクリック → `/contact/?type=trial`
- フォームに「お問い合わせ種別」「名前」「メール」「電話」「希望店舗」「内容」
- **田中の心の声**:
  - 「お問い合わせ種別から選ぶの?『体験予約』のページじゃないんだ」
  - 「内容欄、何を書けばいいか分からない。希望日時の選択肢もない」
  - 「やっぱり、もう少し他のジム見てから決めようかな」
- **判定: ❌ 離脱の確率 50%**(CONTACT流用フォームの摩擦で迷いが生まれる)

### A.7 田中の最終判定
- **総合: 🟡 どちらでもない → 50% で離脱**
- **離脱の最大要因**: 体験予約専用ページの不在 + FAQ少なさ
- **改善されれば**: ✅ 確実に申込
- **田中向け改善提案**:
  1. `/trial/` 専用ページを新設(希望日時2候補・希望プラン・どこで知ったかのみ、3分で送れる粒度)
  2. GYM FAQ を 5件 → 20件に拡張(退会・休会・シャワー・駐車場・振替・キャンセル料 など)
  3. トレーナー紹介に「指導実績例」「得意分野」「コンテスト経歴(あれば)」を追記

## F. ペルソナシミュレーションのメタ的所見

### F.1 「申し込みたい」と判定したペルソナがゼロという事実
- 3ペルソナ全員が **🟡 どちらでもない** で停止
- これは個別ページの完成度ではなく **「サイト全体としての確信形成力」が不足** していることを意味する
- ✅(申し込みたい)に至るには、各ペルソナが少なくとも 2〜3個の「これなら大丈夫」という確信ポイントを得る必要があるが、現在は0〜1個しか得られない構造になっている

### F.2 共通の確信ポイント不足
| ペルソナ | 必要な確信ポイント | 現状の充足度 |
|---|---|---|
| 田中 | 退会・休会条件 / 体験申込の手軽さ / トレーナー実力 | 1/3 |
| 佐藤 | 顧問医・栄養士の実名 / 食の数値 / 法人相談導線 | 0/3 |
| 鈴木 | 親しみのある雰囲気 / 女性向け配慮 / 初心者OKの明示 | 1/3 |

→ 各ペルソナが **3つの確信ポイント中2つ以上を得られる**構造に変えれば、CV率は劇的に改善する。

### F.3 Critic Agent としての結論
ペルソナシミュレーションの結果、**Reviewer Agent が見れない「ユーザー心理の摩擦」が随所に発見**された。
特に B.5(佐藤の体験予約フォーム)、A.6(田中の体験予約フォーム)、C.1(鈴木のTOP威圧感)は、
コードや仕様書だけ見ていれば見えないが、**実物を初見で巡回する**と即座に分かる種類の課題。

これらは `04_priority_actions.md` の最優先項目として再構成する。
